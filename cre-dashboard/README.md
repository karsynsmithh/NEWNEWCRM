# CRE Dashboard — Commercial Real Estate Agent Dashboard

A full-stack web app for managing properties, contacts, deals, and follow-ups.

## Setup

```bash
cd cre-dashboard
npm install
npm start
```

Open **http://localhost:3000** in your browser.

To access from your phone or tablet on the same WiFi network, use the local IP address printed in the console:

```
e.g. http://192.168.1.X:3000
```

## Dev mode (auto-restart on file changes)

```bash
npm run dev
```

## Tech Stack

- **Backend:** Node.js + Express
- **Database:** SQLite (file: `cre_dashboard.db`)
- **Frontend:** Vanilla HTML/CSS/JS — no build step required
